Step 1:
Install the following required mods:
-SiberiaMapPublic
-WindstridesClothingPack
-Namalsk Survival
-VPPAdminTools
-CF
-BuilderItems 

Step 2: Make sure the RedhunterSiberiaPublicKey.bikey is inside your main keys folder on your server

Step 3: Download most recent mission files and profile rar files from github:

https://github.com/redhunt3rr-cell/DayZSiberiaMap

Step 4: Enable cfg.gameplay in your server config and add empty.Siberia to your mission in the config

Step 5: add empty.Siberia mission file to your mission folder and start server

Step 6: Stop Server and add the downloaded profile folder SpawnerBubaku into your profiles folder and reboot server
